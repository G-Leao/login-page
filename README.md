## `01` — ABOUT

A modern **login page** designed with a focus on clean visual hierarchy, usability and responsive design.

The project was developed as a front-end exercise, exploring how a simple authentication interface can combine functionality, visual consistency and a good user experience.

---

## `02` — FEATURES

* Clean login interface
* Responsive layout
* Form inputs
* Password field
* Interactive elements
* Modern visual design
* Mobile-friendly experience

---

## `03` — TECHNOLOGIES

<img src="https://skillicons.dev/icons?i=html,css,js" />

The project focuses on strengthening fundamental front-end skills, including:

`HTML` · `CSS` · `JavaScript` · `Responsive Design`

---

## `04` — DESIGN

The interface was designed around simplicity and usability.

Key principles:

* Clear visual hierarchy
* Minimal and focused interface
* Consistent spacing
* Responsive structure
* Accessible form elements
* Modern visual presentation

---

## `05` — RESPONSIVENESS

The page adapts to different screen sizes:

```text
DESKTOP
   ↓
TABLET
   ↓
MOBILE
```

The goal is to maintain a consistent experience regardless of the device being used.

---

## `06` — PROJECT

This project was created to practice the fundamentals of building polished web interfaces and to improve attention to details such as spacing, typography, responsiveness and user interaction.
